# MOOZ Studio Next

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)](https://github.com/Grigory2009/mooz-studio-next)

**MOOZ Studio Next** — современная, быстрая и надежная альтернатива официальному приложению **Dobot MOOZ Studio (v2.3.2-beta)** для 3-в-1 модульных станков **Dobot MOOZ-1**, **MOOZ-2**, **MOOZ-2 PLUS** и **MOOZ-3**.

Разработано путем глубокого реверс-инжиниринга оригинального дистрибутива MOOZ Studio с полным сохранением совместимости по бинарному протоколу и генерируемому G-коду, но с абсолютно новым интерфейсом, отсутствием багов и проблем с кодировками.

---

## ⚡ Особенности и возможности

### 1. 🖨️ Лазерный гравер (Laser CAM)
- **Grayscale PWM (S0–S255)**: фотореалистичная гравировка полутонов с модуляцией мощности лазера.
- **Дизеринг Floyd-Steinberg & Atkinson**: высокодетализированный растровый перенос фотографий на дерево, кожу, акрил, металл.
- **Бинарный режим**: четкие контуры и резка.
- **Оптимизированная змейка (Serpentine scan)**: чередование направления строк для сокращения холостого хода до 40%.
- Расчет точного времени гравировки и длины траектории.

### 2. 🪵 ЧПУ Фрезерование рельефа (CNC 2.5D Heightmap CAM)
- Прямая генерация 2.5D УП рельефа из полутоновых карт высот (Heightmap).
- Многопроходное послойное фрезерование (Z step-down pass).
- Безопасная высота переходов (`safeHeight`) и управление шпинделем (`M3 S<rpm>` / `M5`).
- Поддержка концевых граверов (V-Bit 10°–90°) и торцевых фрез (Flat End Mill).

### 3. 🧊 3D Печать (CuraEngine Profiles)
- Полные оригинальные профили нарезки CuraEngine (`.def.json`) для:
  - **MOOZ-1 / MOOZ-2**: Декартова кинематика, `130 × 130 × 130 мм`.
  - **MOOZ-2 PLUS**: Декартова кинематика, `200 × 200 × 190 мм`.
  - **MOOZ-3**: Дельта-кинематика, `100 × 100 × 100 мм`.
- Проверенные стартовые и финишные скрипты с очисткой и ретрактом сопла.

### 4. 🕹️ Пульт ручного управления (Jog) и терминал
- Перемещение осей X, Y, Z с настраиваемым шагом (0.1, 1, 10, 50 мм).
- Калибровка нуля (`G92 X0 Y0 Z0`), автопарковка (`G28`).
- Тестовый лазерный прицел на 5% мощности для точной юстировки заготовки.
- Экстренный останов (`M112`).
- Двунаправленный G-code терминал с логом ответов от контроллера.

### 5. 🔌 Бинарный протокол Dobot MOOZ (115200 8N1)
- Пакетный фрейминг: заголовок `0xAA 0xBB`, `Length`, `Version 0x10`, `Config 0x14`, `SeqID`, `CRC8-ATM`, полезная нагрузка и `CRC16-IBM`.
- Прямая связь по USB через виртуальный COM-порт (чип WCH CH340, VID `0x1A86` PID `0x7523`) или через Wi-Fi TCP модуль.

## 🛠️ Архитектура

Приложение спроектировано без тяжелого устаревшего Electron:
- **Backend (`desktop_app/engine.py`)**: автономный движок на Python: генераторы G-кода, протокол обмена MOOZ, менеджер потоков PySerial, встроенный локальный REST API.
- **Frontend (`desktop_app/ui/`)**: 100% автономный SPA (HTML5/CSS3/ES6 Modules). Все стили и векторные иконки встроены локально, работает полностью без интернета.
- **Native Shell (`desktop_app/app.py`)**: запускается в легковесном окне Edge WebView2 через `pywebview`, исключая любые CORS-блокировки локальных файлов.

## 🚀 Установка и запуск

### Запуск из исходного кода:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Grigory2009/mooz-studio-next.git
   cd mooz-studio-next
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python desktop_app/app.py
   ```

### Сборка автономного исполняемого файла (.exe):
Для компиляции в единый переносимый Windows `.exe` (не требующий Python и сторонних библиотек):
```bash
pyinstaller "desktop_app/MOOZ Studio Next.spec"
```
Готовый монолитный бинарный файл создается в директории `dist/MOOZ Studio Next.exe`.
